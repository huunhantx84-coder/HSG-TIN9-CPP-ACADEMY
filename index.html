4. Mô phỏng Euclid từng bước

UCLN(A,B) = UCLN(B,A%B). Thực hiện với A=84 và B=126. Nhấn Bước tiếp để quan sát dòng lệnh tương ứng.

① Code C++ — tô sáng dòng đang thực hiện

Euclid.cpp
1while (B != 0) {
2 long long r = A % B;
3 A = B;
4 B = r;
5}
6UCLN = A;

B126
