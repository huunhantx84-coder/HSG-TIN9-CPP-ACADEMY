Hướng giải: thử lần lượt Y = X + 1, X + 2, …; dùng hàm hopLe(), tách chữ số và mảng đánh dấu.
Chặng 1 / 5

Đọc hiểu đề

Một đơn vị vận chuyển dùng mã vận đơn là số nguyên dương có các chữ số đôi một khác nhau, viết ở hệ thập phân và không có chữ số 0 thừa ở đầu. Mã đang lưu là X có thể chưa hợp lệ.

Yêu cầu: tìm mã hợp lệ nhỏ nhất lớn hơn X.

Dữ liệu

LUYEN15.INP: một số nguyên X.
10 ≤ X < 10⁹.

Kết quả

LUYEN15.OUT: mã cần tìm. Đề bảo đảm luôn có đáp án.

Ví dụ đề bài

Input: 2022
Output: 2031

Các chữ số 2, 0, 3, 1 đều khác nhau. Trong khoảng 2023…2030, mọi số đều lặp ít nhất một chữ số.

Phân bố điểm trong đề

40%: X ≤ 10000; 30%: 10000 < X ≤ 10⁶; 30%: 10⁶ < X < 10⁹.

“Đôi một khác nhau” nghĩa là không có hai vị trí mang cùng một chữ số. Mã 2030 không hợp lệ vì chữ số 0 xuất hiện hai lần.
Với X = 2022, mã nào đúng yêu cầu?
Chặng 2 / 5

Khám phá: vì sao 2031 là nhỏ nhất?

Tự nhập một số để quan sát chữ số trùng. Công cụ này kiểm tra mã anh/chị nhập, chưa tự tìm mã kế tiếp.

Quan sát chuỗi ứng viên

2023 → 2024 → … → 2029 → 2030 → 2031

2023…2029 đều có hai chữ số 2. Số 2030 có hai chữ số 0. Số 2031 không có chữ số lặp, nên dừng.

Với 2023, hàm tách chữ số theo thứ tự 3 → 2 → 0 → 2; gặp lại 2 thì trả false ngay.

Khi hàm hopLe(Y) trả false, chương trình cần làm gì?
Chặng 3 / 5

Hình thành thuật toán: tìm và kiểm tra

Việc 1 — Kiểm tra một số

  1. Tạo mới daCo[10], mọi ô đều false.
  2. Khi n > 0, lấy cs = n % 10.
  3. Nếu daCo[cs] đã true, trả false ngay.
  4. Nếu chưa gặp, đánh dấu daCo[cs] = true; bỏ chữ số vừa xét bằng n /= 10.
  5. Tách hết mà không trùng thì trả true.

Việc 2 — Tìm số nhỏ nhất

  1. Nhập X; đặt Y = X + 1.
  2. Trong khi !hopLe(Y) đúng, tăng Y.
  3. Gặp Y hợp lệ đầu tiên thì dừng và xuất Y.

Thử theo thứ tự tăng, không bỏ sót số nào nên nghiệm đầu tiên là nghiệm nhỏ nhất lớn hơn X.

Phân biệt Y và n: Y là ứng viên trong main. n là bản sao nằm trong hàm hopLe. Lệnh n /= 10 không làm Y thay đổi. daCo là mảng cục bộ, được tạo mới mỗi lần gọi hàm.

Đúng về kết quả; cần chú ý tốc độ

Gọi K là số ứng viên đã thử, D là số chữ số tối đa: thời gian O(K × D), bộ nhớ phụ O(1) vì chỉ có 10 cờ.

Ví dụ 2022 chỉ kiểm tra 9 số. Với X = 987654321, đáp án là 1023456789 và phải thử 35.802.468 số. Chưa thể khẳng định đạt toàn bộ điểm khi chưa biết giới hạn thời gian.

Đề bảo đảm có đáp án. Chương trình dùng long long vì kết quả có thể có 10 chữ số.

Gợi ý tự đối chiếu (không chấm tự luận tự động)

Tham số n nhận một bản sao giá trị Y. Phép gán và chia n chỉ tác động đến bản sao bên trong hàm.

Khi chuyển từ kiểm tra 2023 sang kiểm tra 2024, daCo cần ở trạng thái nào?

    Tự lập trình và kiểm tra

    Trước khi mở code: với X = 98, mã nhỏ nhất lớn hơn X là gì?

    #include <bits/stdc++.h>
using namespace std;

bool hopLe(long long n) {
    bool daCo[10] = {false};
    while (n > 0) {
        int cs = n % 10;
        if (daCo[cs]) {
            return false;
        }
        daCo[cs] = true;
        n /= 10;
    }
    return true;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    freopen("LUYEN15.INP", "r", stdin);
    freopen("LUYEN15.OUT", "w", stdout);
    long long X;
    if (cin >> X) {
        long long Y = X + 1;
        while (!hopLe(Y)) {
            Y++;
        }
        cout << Y;
    }
    return 0;
}
