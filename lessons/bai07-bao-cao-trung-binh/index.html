Từ số liệu trung bình đến doanh thu thật — tư duy ngược, biến và vòng lặp for

CHẶNG 1 / 5

Đọc hiểu bài toán

Một cửa hàng ghi lại Bᵢ — doanh thu trung bình mỗi ngày, tính từ ngày 1 đến ngày i. Hãy khôi phục doanh thu thực tế từng ngày theo thứ tự. Doanh thu ngày là số nguyên không âm, dữ liệu đảm bảo có đáp án hợp lệ.

LUYEN07.INP

Dòng 1: N (1 ≤ N ≤ 100000).
Dòng 2: N số Bᵢ (0 ≤ Bᵢ ≤ 10⁹).

5
20 30 25 35 40

LUYEN07.OUT

N số nguyên là doanh thu từng ngày, theo thứ tự.

20 40 15 65 60

Lưu ý: B₃=25 không có nghĩa doanh thu riêng ngày 3 là 25; đó là trung bình của 3 ngày đầu tiên.

Khám phá quy luật: tổng mới trừ tổng cũ

Thay đổi năm số trung bình (ví dụ mặc định) và chọn ngày cần khôi phục. Hãy đoán kết quả trước khi bấm tính.

Chọn ngày và nhập dự đoán để xem phép tính.
CHẶNG 3 / 5

Từ quy luật đến chương trình

Tổng từ ngày 1 đến i = i × Bᵢ
Doanh thu riêng ngày i = (i × Bᵢ) − tổng đến ngày i−1
  1. Khởi tạo tongTruoc = 0.
  2. Lặp i từ 1 đến N, đọc trung bình B.
  3. Đặt tongHienTai = B * i.
  4. Đặt doanhThu = tongHienTai - tongTruoc, rồi in ra.
  5. Cập nhật tongTruoc = tongHienTai trước vòng tiếp.

Chú ý: Chương trình không cần mảng; chỉ cần biến, for, if. Dùng long long vì tổng có thể tới 10¹⁴. Thời gian O(N); bộ nhớ O(1).

Ngày kế tiếp cần biết tổng doanh thu tính đến ngày hiện tại. Vì vậy phải lưu tongHienTai làm tongTruoc trước khi lặp tiếp.
CHẶNG 4 / 5

Mô phỏng từng dòng code

Hai cột: C++ được tô sáng từng bước và trạng thái các biến. Mô phỏng hỗ trợ 1–12 ngày để dễ quan sát.

Cột 1 · Mã C++

#include <bits/stdc++.h>
using namespace std;

int main() {
    freopen("LUYEN07.INP", "r", stdin);
    freopen("LUYEN07.OUT", "w", stdout);

    int N;
    cin >> N;
    long long B;
    long long tongTruoc = 0;
    for (int i = 1; i <= N; i++) {
        cin >> B;
        long long tongHienTai = B * i;
        long long doanhThu = tongHienTai - tongTruoc;
        cout << doanhThu;
        if (i < N) cout << " ";
        tongTruoc = tongHienTai;
    }
    cout << '\n';
    return 0;
}
