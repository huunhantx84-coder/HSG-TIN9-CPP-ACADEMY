Đọc hiểu đề bài

Đội tình nguyện có A quyển vở và B cây bút. Họ muốn làm nhiều túi quà giống hệt nhau; mỗi túi có cùng số vở và cùng số bút. Phải dùng hết đồ, không được chia nhỏ bất kỳ món nào.

Đầu vào · LUYEN01.INP

Một dòng gồm hai số nguyên A, B; 1 ≤ A, B ≤ 1018.

Đầu ra · LUYEN01.OUT

Dòng 1: số túi nhiều nhất.
Dòng 2: số vở và số bút trong một túi.

Ví dụ đầu vào
84 126
Ví dụ đầu ra
42
2 3
CHẶNG 2 / 5

Khám phá cách chia đều

Thử chọn số túi k. Nếu A và B cùng chia hết cho k, phép chia là hợp lệ. Hãy quan sát số vở, số bút và phần dư.

Quan sát: Có thể dùng for thử các số túi nhỏ, nhưng nếu A, B lên tới 1018 thì cách thử lần lượt sẽ quá chậm.
CHẶNG 3 / 5

Hình thành thuật toán

01

Số túi k phải chia hết cả A và B: A % k == 0 và B % k == 0.

02

Muốn số túi lớn nhất, tìm UCLN(A, B).

03

Với Euclid: lặp r = a % b; a = b; b = r; đến khi b == 0.

04

Đặt k = a. Số vở/túi là A/k, số bút/túi là B/k.

Thời gian: O(log(min(A,B))). Bộ nhớ phụ: O(1). Dùng long long vì A, B có thể lên tới 1018.
Số túi k phải là ước của cả A và B. Trong tất cả các ước chung, ước lớn nhất cho số túi nhiều nhất.
CHẶNG 4 / 5

Mô phỏng Euclid từng bước

Code C++ · dòng đang thực hiện

#include <bits/stdc++.h>
using namespace std;

int main() {
    freopen("LUYEN01.INP", "r", stdin);
    freopen("LUYEN01.OUT", "w", stdout);

    long long A, B;
    cin >> A >> B;

    long long a = A, b = B;
    while (b != 0) {
        long long r = a % b;
        a = b;
        b = r;
    }
    long long k = a;
    cout << k << '\n';
    cout << A / k << " " << B / k << '\n';
    return 0;
}
