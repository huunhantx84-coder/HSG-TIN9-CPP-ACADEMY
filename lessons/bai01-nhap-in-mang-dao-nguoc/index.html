Hình thành thuật toán

1. Nhập n và n phần tử a[0] ... a[n-1] bằng vòng lặp for tăng i.

2. Gán i = n - 1 để bắt đầu từ cuối mảng.

3. Khi i >= 0, in a[i], rồi giảm i--.

4. Khi i == -1, điều kiện sai: dừng; không truy cập a[-1].

Ba cách diễn đạt cùng một hành động
for   : for (int i=n-1; i>=0; i--)
while : int i=n-1; while (i>=0) { ...; i--; }
do...while: int i=n-1; do { ...; i--; } while (i>=0);

Vì n ≥ 1 nên mẫu do...while ở đây chạy ít nhất một lần là phù hợp. Lời giải chính dùng for.

Mảng n phần tử được đánh chỉ số 0, 1, ..., n−1. Chỉ số n nằm ngoài phạm vi mảng.

Độ phức tạp: thời gian O(n), bộ nhớ O(n) để lưu n phần tử.

Mô phỏng code chạy từng bước

Quan sát dòng chương trình được tô sáng, chỉ số i, phần tử hiện tại và Output đang được in.

Cột 1 · Code C++

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    int a[1000];

    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    for (int i = n - 1; i >= 0; i--) {
        cout << a[i];
        if (i > 0) cout << " ";
    }
    cout << '\n';
    return 0;
}
