Bài 09 — Nhật ký quỹ lớp

Mảng một chiều · FOR · IF · long long

Thủ quỹ chỉ ghi số dư

Trước khi theo dõi, quỹ có B đồng. Sau mỗi giao dịch, thủ quỹ ghi số tiền còn lại S[i]. Mỗi lần ghi ứng với một giao dịch; quỹ không âm.

Hãy khôi phục từng giao dịch: thu là số dương, chi là số âm, không đổi là 0. Tính thêm tổng thu và tổng chi; tổng chi ghi không âm.

LUYEN09.INP: N, B; tiếp theo N số dư.
LUYEN09.OUT: dòng 1 là N giao dịch; dòng 2 là tổng thu và tổng chi.
1 ≤ N ≤ 100.000; 0 ≤ B, S[i] ≤ 10¹².

Đừng nhầm số dư với giao dịch

Ban đầu có 100. Sau lần ghi đầu có 150.

Số 150 biểu diễn điều gì?

Input mẫu

Gợi ý khi chưa tìm ra

Số dư sau = Số dư trước + Giao dịch. Muốn tìm số hạng chưa biết, em làm phép tính gì?

Từ câu chuyện đến công thức

Quỹ mới = Quỹ cũ + Giao dịch.

Trong đó giao dịch được tính là:

giaoDich = S[i] - S[i - 1];

Đặt S[0] = B để dùng chung công thức cho cả giao dịch đầu tiên.

Dương → Thu

tongThu += giaoDich

Âm → Chi

tongChi += -giaoDich

Bằng 0

Không cộng tổng nào

Em hãy kể lại cách làm

  1. Nhập dữ liệu, đặt S[0] = B.
  2. Khởi tạo hai tổng bằng 0.
  3. Duyệt i từ 1 đến N, tính hiệu hai số dư.
  4. Xuất giao dịch và cộng vào tổng phù hợp.
  5. Xuất hai tổng ở dòng thứ hai.

O(N) thời gian · O(N) bộ nhớ với mảng. Dùng long long: tổng có thể tới cỡ 10¹⁷.

Đối chiếu lời giải thích của em

Số dư sau gồm số dư trước cộng giao dịch, nên lấy số dư sau trừ số dư trước sẽ còn giao dịch. Khoản chi mang dấu âm, nhưng tổng chi cần không âm nên cộng độ lớn của nó.

Phần viết này để em tự đối chiếu hoặc nhờ thầy nhận xét, không tự chấm nội dung.

Code C++

1#include <bits/stdc++.h>
2using namespace std;
3long long S[100005];
4int main() {
5 ios::sync_with_stdio(false);
6 cin.tie(nullptr);
7 freopen("LUYEN09.INP", "r", stdin);
8 freopen("LUYEN09.OUT", "w", stdout);
9 int N;
10 long long B;
11 cin >> N >> B;
12 S[0] = B;
13 for (int i = 1; i <= N; ++i) {
14 cin >> S[i];
15 }
16 long long tongThu = 0, tongChi = 0;
17 for (int i = 1; i <= N; ++i) {
18 long long giaoDich = S[i] - S[i - 1];
19 if (i > 1) cout << ' ';
20 cout << giaoDich;
21 if (giaoDich > 0) {
22 tongThu += giaoDich;
23 } else if (giaoDich < 0) {
24 tongChi += -giaoDich;
25 }
26 }
27 cout << '\n';
28 cout << tongThu << ' ' << tongChi << '\n';
29 return 0;
30}

Thử một trường hợp mới
Dữ liệu luyện tập: B = 200; các số dư 150, 150, 0, 80.
Xem lời giải sau khi tự làm
-50 0 -150 80
80 200
200 + 80 − 200 = 80, đúng số dư cuối.
Trang kiểm tra kết quả số, không biên dịch code C++ của học sinh.
Ba lỗi cần tránh
① Lấy giao dịch đầu bằng S[1], quên tiền có sẵn B.
② Cộng số âm vào tổng chi, khiến tổng chi âm.
③ Dùng int cho số dư hoặc hai tổng.
Tự kiểm tra trường hợp biên
N = 1; chỉ thu; chỉ chi; mọi số dư bằng nhau; số dư về 0; số tiền lớn.
